# Homonoia — swarm-autonomy concept site

A single-file landing page for a dual-use AI drone-swarm startup, styled after blue stipple
paintings of classical architecture.

- **Live 3D world** (three.js r128 from cdnjs): a Doric temple, dunes and sea, plus a 2,400-agent
  swarm (boids with k = 7 topological neighbours) that forms a murmuration, a ring-hatched sphere,
  a search lattice and a cumulus cloud as you scroll. A post-process shader maps the grey render to
  the ultramarine palette with stochastic stipple grain.
- **Swarm lab**: a scripted fleet vs. a swarm on local rules; "Cut the link" shows the difference.
- **Sourced content**: every claim about the world is footnoted to the Sources section.

Open `index.html` in a browser (it needs network access for the CDN script and Google Fonts).
